The build, step by step

From a blank starter to a deployed product.

The project extends the nahaQUT/sampleapp_IFQ636 auth starter into a real medication-adherence platform, following every phase of the lifecycle.

01 · Requirements & SysML

Designed before coding

Captured user/admin requirements, then modelled the system in SysML: a requirement diagram (with «deriveReqt»/«satisfy» traceability), use-case, BDD, IBD, activity, sequence and state-machine diagrams.

View diagrams →
02 · Project management (JIRA)

Planned as epics, stories & sprints

A Scrum board with 6 epics broken into 11 user stories and 25 sub-tasks, organised across two sprints — Medication Management, Reminder Scheduling, Dose Tracking, Admin Console, Auth and DevOps.

Open Jira board →
03 · UI/UX (Figma)

Wireframes → hi-fi → interactive prototype

Low-fidelity wireframes and four polished high-fidelity screens (Login, Dashboard, Medications, Admin) wired into a clickable prototype with smart-animate transitions.

Open Figma →
04 · Backend (Node · Express · MongoDB)

Owner-scoped CRUD with role-based access

Medication, Reminder, DoseLog and Admin APIs — every query scoped to the authenticated patient, JWT auth, an admin guard, and adherence computed via a MongoDB aggregation. 13 Mocha+Sinon tests run DB-free.

05 · Frontend (React · Tailwind)

Dashboard, CRUD pages & admin panel

A responsive React SPA: adherence dashboard with one-tap dose logging, full medication & reminder CRUD, dose history, and a role-gated admin console.

06 · Version control (GitHub)

Clean, reviewable history

Feature-branch workflow: main + three feature branches, each merged through a pull request, producing a structured, traceable commit history.

See the pull requests →
07 · CI/CD (GitHub Actions)

Automated test → build → deploy

Every push to main runs the test suite, builds the frontend on the runner, ships it to EC2 over SSH, and reloads PM2 — using a protected production environment with encrypted secrets.

View pipeline runs →
08 · Deployment (AWS EC2)

Live on the public internet

Running on an Ubuntu EC2 instance (Sydney) — backend under PM2 serving the React build, MongoDB in Docker. One public URL, reachable right now.
